# PrepMed

Uma aplicação web PWA para gerenciamento de medicamentos de uso doméstico, com as seguintes funcionalidades:

* Gerenciamento de medicamentos: cadastrar, editar e excluir medicamentos.
* Alertas de vencimento: enviar notificações para medicamentos próximos do vencimento.
* Busca e filtros: incluir a opção de buscar medicamentos por nome ou filtrar por categorias, data de vencimento, etc.
* Categorias de medicamentos: permitir agrupar medicamentos por categoria (ex: antibióticos, analgésicos).
* Histórico de uso: rastrear quando e quantas vezes um medicamento foi utilizado.
* Armazenamento local: use IndexedDB para armazenar os dados.
* Compartilhamento de dados: permitir exportação e importação dos dados (ex: backup).
* Interface minimalista: estilo preto e branco, visual limpo e moderno.
* Modo escuro: adicionar uma opção de modo escuro para maior conforto visual.
* Tecnologias: utilize apenas HTML, CSS e JavaScript puro, sem frameworks. Use o Bootstrap para modais de formulários e o SweetAlert2 para exibir alertas.
* Design responsivo: a interface deve ser adaptável tanto para dispositivos móveis quanto para desktop.
* PWA: inclua um manifesto Android e um Service Worker para garantir que o app funcione offline e possa ser instalado como um PWA.
Algumas melhorias potenciais para o futuro:

Implementar um sistema mais robusto de categorias
Adicionar um histórico de uso mais detalhado
Melhorar a interface do usuário com animações e transições
Implementar um sistema de backup automático
Adicionar funcionalidades de lembrete para tomar medicamentos

O nome PrepMed é uma combinação de "Prep" (de "preparedness", que significa prontidão ou preparação) e "Med" (de medicamentos). Esse nome sugere que o aplicativo está focado em preparar e gerenciar adequadamente o estoque de medicamentos em casa, algo essencial no contexto de sobrevivencialismo. Ele passa a ideia de estar sempre pronto para qualquer situação em que seja necessário ter medicamentos disponíveis, o que se alinha com o conceito de autopreservação e gerenciamento eficiente.
